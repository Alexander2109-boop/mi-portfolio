# CRM Empresarial - Grupo 5 

## Cómo ejecutar el proyecto en menos de 2 minutos

### Requisitos
- XAMPP / Laragon / MAMP / WAMP (recomendado XAMPP 8.2 o superior)
- Visual Studio Code (o cualquier editor)
- Navegador moderno (Chrome/Firefox)

### Pasos detallados

1. Copia toda la carpeta `codigo` en tu htdocs (ej: `C:\xampp\htdocs\CRM_Entrega2`)

2. Abre XAMPP → Inicia Apache y MySQL

3. Abre phpMyAdmin → Crea una base de datos llamada `crm_empresa`

4. Importa el archivo `base_de_datos/crm_empresa.sql` (está en el .zip)

5. Abre Visual Studio Code → Abre la carpeta del proyecto

6. Abre el navegador y ve a:  
   http://localhost/CRM_Entrega2

7. Credenciales de prueba:
   - Admin: admin@crm.com     / contraseña: 123456
   - Vendedor: ventas@crm.com / contraseña: 123456

¡Listo! Ya tienes el CRM 100% funcional.
